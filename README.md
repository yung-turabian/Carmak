# Links Render Package

# About

This is an attempt to branch off from the standard library of the [Links programming language](https://github.com/links-lang/links/). 
This could be apart of its default toolchain but for many this would be
overkill and untouched. The idea with the rendering library is geared more towards
game development, interactions with WebGl and a better interface with the
underlying JavaScript canvas.
